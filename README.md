# The Standing Page

*A daily editorial publication of small games. Five plates, two minutes, fresh at midnight.*

This repository deploys to [thestandingpage.com](https://thestandingpage.com) via Vercel. Every push to `main` triggers a deployment.

## Files

- `index.html` — the holding page, masthead, contents promise, signup
- `plate-i.html` — **The Reading.** A passage with a missing word; supply it
- `plate-ii.html` — **The Year.** A sentence; place it in time
- `plate-iv.html` — **The Ladder.** Five things; arrange them in their right order

## Plates yet to come

- Plate III — **The Figure** — one number, three contexts
- Plate V — **The Order** — two events, which came first

Plates VI, VII, VIII (The Misnomer, The Match, The Compass) live in design notes for after launch.

## Stack

Vanilla JavaScript. HTML5 single-file pattern. No framework. No build step. No backend. The publication is what it appears to be: cream paper, ink type, one paper-red accent. It looks the same in dark mode, with the colours inverted.

Each plate has a buffer of editorial content rotated daily. Daily mode shows the same item to everyone on the same UTC day; endless mode picks from the buffer at random. Scoring is four-tier (★★★★ to —) with a star caption in editorial voice.

## Status

Soft-launch test. Three plates playable, two forthcoming. Sharing with a small list of friends-and-family readers before any wider launch.
